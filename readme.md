# EcoEnzyme
### Biowaste Management and Sustainability Tool

## Project Overview

EcoEnzyme is a Python-based educational application that
helps students record and organise biodegradable waste data.
It demonstrates how simple programming techniques can support
environmental monitoring and biotechnology learning.

## Objectives

- Understand biodegradable waste classification.
- Maintain digital records of waste quantities.
- Calculate category-wise waste totals.
- Explore the role of biotechnology in sustainability.

## Features

- Add biowaste records.
- Select from predefined waste categories.
- Record waste quantities in kilograms.
- View all saved records.
- Generate a category-wise quantity summary.
- Store information using CSV file handling.

## Technologies Used

- Python 3
- CSV module
- Collections module
- Command-line interface

## Project Structure

    ecoenzyme-waste-management/
    ├── EcoEnzyme.py

The CSV data file is generated automatically when
the first record is added.

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project directory.
4. Run:

       python EcoEnzyme.py

   On some systems, use:

       python3 EcoEnzyme.py

5. Select an option from the displayed menu.

## Example

Waste name: Banana Peels
Category: Fruit and Vegetable Waste
Quantity: 2.5 kg

## Applications

This project can be used for introductory programming
practice, environmental data recording and learning about
sustainable biotechnology.

## Limitations

The application records quantities entered by the user.
It does not identify waste automatically or measure
biological decomposition and enzyme activity.
